## 必须可达的约束

1. **三栏 grid + 顶部 banner**：用 CSS Grid `.triage-grid { grid-template-columns: 1fr 1fr 1.4fr }`；banner 用 `.degraded-banner` / `.cxr-alert-banner` 两类 class。
2. **阳性红标 + 草稿灰底 + 降级 banner**：所有颜色用 CSS 变量（`--cxr-positive`, `--cxr-degraded`, `--cxr-signed`），不内联颜色。
3. **SSE 实时更新**：浏览器端 `EventSource('/api/sse')` 监听 4 类事件（`new_study` / `draft_ready` / `state_change` / `alert`），状态变化不刷新页面。
4. **所见必含草稿标识**：每条 `finding_text` 渲染前都要包含「（草稿 / 未经医师确认）」字样，CSS class `.draft-marker` 给灰底斜纹。
5. **移动端响应式**：`@media (max-width: 768px)` 单栏堆叠，按钮居中。

## 必不出现的元素

- 概念图 / 设计稿样张（实测截图由 Task 37 采集到 `docs/screenshots/`）。
- 任何形式的「事后效果图」（不允许把概念图当实测图冒充）。
- 来自灵感库项目的截图、配色或 logo。
